# Reference CrossPoint Files

Unmodified reference material from the upstream CrossPoint reader firmware,
kept here so the custom Anki builds in `../custom-bin-builds/` can be compared
against a known-good stock binary.

Upstream project: <https://github.com/crosspoint-reader/crosspoint-reader>

## Contents

| File | Description |
| --- | --- |
| `reference-xteink_x4_x3-1.6.0_beta_RC02.bin` | Stock CrossPoint 1.6.0 beta RC02 release build for Xteink X4/X3 (placeholder — see note below). |

> **Note:** the `.bin` in this folder is currently a 2-byte placeholder, not a
> flashable image. Replace it with the real asset from the upstream release page
> if a stock binary is needed for comparison.

Nothing in this folder is patched or built by this repository; see
`../firmware/` and `../custom-bin-builds/` for the Anki-enabled builds.
